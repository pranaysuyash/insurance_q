# CoverWise App Store and Google Play Readiness: End-to-End User Flows

**Audit date:** 2026-10-12  
**Lane:** End-to-end user flows  
**Scope:** Flutter navigation, screens, providers and services; FastAPI route and payload matching; Render and Supabase source configuration relevant to these flows.  
**Evidence level:** Static source inspection only. No app was launched, no tests were run, no production service was contacted, no package was installed, and no Git command was used. Runtime, device, store, and live-provider behavior is marked **UNVERIFIED**.

## Status key

- **WORKS-BY-INSPECTION:** the inspected client path and available backend contract agree, or the flow is intentionally local and its behavior is apparent from source.
- **PARTIAL:** a useful path exists, but a known gap, mismatch, or limited launch scope prevents the requested flow from being complete.
- **BROKEN:** source shows a path that cannot reach its declared destination or handle a required response correctly.
- **UNVERIFIED:** source cannot establish the actual platform, deployment, provider, or device result.
